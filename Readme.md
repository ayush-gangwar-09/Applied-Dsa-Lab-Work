# Applied Data Structures & Algorithms Lab

A collection of **15 lab assignments and 45 Java programming tasks** for the BCS553 – Applied Data Structures & Algorithms Lab. This repository contains Java programs covering arrays, sorting, searching, object-oriented programming, inheritance, recursion, subsets, and permutations.

## 📌 About the Project

This repository is created for lab practicals and academic practice. Each program includes its objective, algorithm, Java source code, sample output, time and space complexity, and viva-voce questions.

## 🎯 Objectives

- Understand basic array operations.
- Implement sorting algorithms such as Bubble Sort and Selection Sort.
- Perform Linear Search and Binary Search.
- Learn classes, objects, and constructors in Java.
- Understand inheritance, method overriding, and polymorphism.
- Solve problems using recursion.
- Perform recursive array operations.
- Generate subsets and permutations using recursion and backtracking.
- Analyze time and space complexity.

## 📈 Complexity Analysis

The programs demonstrate different algorithmic complexities:

| Complexity | Example |
|---|---|
| O(1) | Array index access |
| O(log n) | Binary Search |
| O(n) | Linear Search and array traversal |
| O(n²) | Bubble Sort and Selection Sort |
| O(2ⁿ) | Generating all subsets, excluding output costs |
| O(n!) | Generating permutations, excluding output costs |

The exact complexity depends on the specific implementation and whether output-generation costs are included.
